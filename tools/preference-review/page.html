What this review covers

A pinned snapshot of software-related pstack instructions, supporting tool code, and Kishu's changes. Original replacements and repeated documentation have separate labels. This inventory is a completeness check, not a claim that every paragraph is a distinct policy.

Reading the labels

Current means bundled in Kishu, subject to the router, user/project instructions, and host permissions. Most leaf skills apply only when selected or relevant. Replaced is historical comparison. Reference may repeat upstream defaults. Executable checks run only when their tool is invoked.

Impeccable's design system, the ADHD communication policy, and chat/prose-only skills are excluded. Your private host configuration and other installed plugins are not copied into this shareable review. Source-block coverage is generated; plain-English notes and suggestions are editorial interpretations.
