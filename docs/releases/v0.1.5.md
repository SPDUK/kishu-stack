# Kishu v0.1.5

Kishu's first public release in the v0.1 series introduces stable release updates. `/kishu update` now installs the latest published stable GitHub Release, leaving unreleased `main` changes out of user installations.

- Install a specific published version, including an explicit rollback, with `--version 0.1.5`.
- Check the release tag against the package version and report the exact installed commit.
- Preserve local changes, development branches, unpublished commits and existing model preferences. Use a new default release checkout at `~/.kishu/releases`; older `~/.kishu/source` checkouts remain untouched.
- Stop safely on unavailable releases, network errors, drafts, prereleases and mismatched versions. Restore the previous source checkout if the installer fails; host-side partial changes may still need recovery.
- Publish release archives and checksums only after Windows and Ubuntu verification succeeds.

## Install

Python 3.11+, Git and the target host's installation tools are required.

```sh
git clone --branch v0.1.5 --single-branch https://github.com/SPDUK/kishu-stack.git
cd kishu-stack
python scripts/kishu.py install --harness codex
```

Start a new chat or refresh skills, then use `$kishu:kishu-mode` for work and `$kishu:kishu update` for future stable updates. The attached ZIP contains the complete generated `plugin/` bundle; source scripts are available in the tagged repository.

## Compatibility

Native Codex installation and skill discovery have an isolated integration check. Cursor and Claude Code packaging is provided, but live loading in those applications remains unverified. The standalone skill export retains its complete referenced libraries.

This release includes Kishu mode, its design taste engine and ADHD-aware communication, with the existing interactive demo collection. Upstream attributions and licenses remain included. No new model-performance or cost-saving claims are made.
