# Kishu v0.1.6

Kishu now explicitly delivers image proof in the main agent's final reply, including screenshots captured by sub-agents. This release also refreshes the bundled design taste engine.

- Require the main agent to retrieve and inspect image artifacts, then embed or attach them with a useful caption. A private tool result or a sub-agent's description does not count as delivery.
- Specify Codex image formatting, including absolute paths and paths containing spaces. Recover missing artifacts or report the evidence gap; explain when a host cannot display images inline.
- Update Impeccable from 4.8.0 to 4.8.2 and its engine from 0.1.18 to 0.1.22, including Windows launcher fixes, live editing improvements, and updated audit and design guidance.
- Refresh the pstack repository pin to the latest reviewed revision; its bundled subtree is unchanged. The i-have-adhd revision is unchanged. Kishu preferences, model configuration behavior, and upstream licenses are preserved.

## Install or update

Existing installations can use `$kishu:kishu update` in Codex or their host's Kishu update command after this release is published.

```sh
git clone --branch v0.1.6 --single-branch https://github.com/SPDUK/kishu-stack.git
cd kishu-stack
python scripts/kishu.py install --harness codex
```

Refresh skills or start a new chat after installation. The attached ZIP contains the complete generated plugin bundle, with its checksum in `SHA256SUMS.txt`.

## Verification and limits

The release workflow runs the regression suites and package checks on Windows and Ubuntu before publishing. Native Codex installation, skill discovery, same-version refresh, and package matching also have a local integration check.

A sub-agent captured a local HTML page using headless Chromium; the main agent opened the saved PNG and embedded it in its final reply. This exercised the artifact handoff without Computer Use. It does not establish rendering on every client or host. Live Cursor and Claude Code loading and the updated design workflows remain unverified end to end.
