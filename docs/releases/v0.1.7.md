# Kishu v0.1.7

Kishu now uses your configured `swarm workers` model for live verification in multi-PR plans. The planner hands back the Markdown checklist and its validation result, then waits for your go-ahead before implementation.

- Updated the routing foundation to pstack 0.15.44. Kishu includes all 22 playbooks in the revised catalog, including Investigation, Runtime forensics, and Trace forensics. The new worker brief carries your scope and evidence requirements into delegated work.
- Kept Kishu’s adapted plan checker after its removal upstream. Both the native plugin and standalone export link to their packaged copy.
- Updated the design taste engine to Impeccable 4.10.0 with engine 0.1.27. The update adds guidance for reviewing motion and reduced-motion behavior. ADHD-aware communication uses i-have-adhd 0.4.1.

## Install or update

In Codex, run `$kishu:kishu update` and start a new chat. For a fresh install, run the following commands.

```sh
git clone --branch v0.1.7 --single-branch https://github.com/SPDUK/kishu-stack.git
cd kishu-stack
python scripts/kishu.py install --harness codex
```

The release assets include the plugin ZIP and its SHA-256 checksum. The [site FAQ](https://spduk.github.io/kishu-stack/#faq) includes an example multi-PR planning request.
