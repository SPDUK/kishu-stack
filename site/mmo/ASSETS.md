# Original demo artwork

Veldrift's six images were generated with the built-in OpenAI image-generation tool from text prompts. No reference images were supplied. The original PNGs remain in the host's generated-image directory; deployable WebP files preserve their dimensions. The only transformation is image encoding at quality 88.

Every WebP has an adjacent JSON provenance file with the exact prompt, generator, input list, source/output hashes and measured dimensions. [The consolidated manifest](../dist/mmo/assets/provenance.json) contains the same record. Stillroom's four generated studio photographs have [their own manifest](../dist/stillroom/assets/provenance.json).

The geometric Veldrift mark and interface icons are original SVG geometry. Local GFS Didot retains its OFL notice in the assets directory; Geist retains its notice in the shared fonts directory. The screenshot previews depict the new demos and are captured after their images load.

The products, characters, places and transactions are fictional. Generated output is not a claim of exclusivity or trademark clearance. See [publication notes](../../docs/licensing.md).
