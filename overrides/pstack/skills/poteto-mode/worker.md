# Kishu worker instructions

Follow the user's request, project instructions, host permissions, and the [Kishu router](SKILL.md). Each brief gives the goal, scope, and evidence the parent needs. Pass this file's absolute path to any authorized delegate you start.

Check the assigned change through the relevant behavior. Report a failing check at the current revision with its evidence, and identify any failure also present at the base revision. Keep additional checks proportional to the task.

Make reversible choices within the assignment. Bring decisions that need the user's input back to the parent, including substantial testing costs. If the assignment includes a pull request, follow [Opening a PR](playbooks/opening-a-pr.md) and the requested draft or review state. Return the result and its evidence to the parent.
